sandbox.ci.alert module – Manage the state of a SCOM alert and check gh-pages deployment.

Note

This module is part of the sandbox.ci collection (version 1.0.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install sandbox.ci.

To use it in a playbook, specify: sandbox.ci.alert.

New in sandbox.ci 1.0.0

  • Synopsis

  • Parameters

  • Examples

  • Return Values

Synopsis

  • Updates the properties or resolution state of an existing SCOM alert identified by its GUID.

  • This module is a copy from microsoft.scom used to test the CI integration target detection mechanism.

Examples

    alert_id: "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
    resolution_state: closed
