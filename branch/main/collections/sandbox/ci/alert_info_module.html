sandbox.ci.alert_info module – Retrieve SCOM alert information.

Note

This module is part of the sandbox.ci collection (version 1.0.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install sandbox.ci.

To use it in a playbook, specify: sandbox.ci.alert_info.

New in sandbox.ci 1.0.0

  • Synopsis

  • Parameters

  • Examples

  • Return Values

Synopsis

  • Retrieves one or more SCOM alerts, with optional filtering by criteria string.

  • This module is a copy from microsoft.scom used to test the CI integration target detection mechanism.

Parameters

Parameter

Comments

criteria

string

SCOM-style SQL-like criteria string to filter alerts.

monitoring_object

string

Filter alerts by monitoring object display name (substring match).

resolution_state

string

Filter alerts by resolution state.

Choices:

  • "new"

  • "closed"

  • "any"

severity

string

Filter alerts by severity level.

Choices:

  • "information"

  • "warning"

  • "critical"

Examples

- name: Get all active SCOM alerts
  sandbox.ci.alert_info:
  register: alert_result

- name: Get critical alerts
  sandbox.ci.alert_info:
    criteria: "Severity = '2'"
  register: critical_alerts

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

alerts

list / elements=dictionary

List of matching SCOM alert objects.

Returned: always
